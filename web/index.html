Questions about Backrow

Something else? Open an issue on GitHub

Is Backrow free?

Yes. No ads or paid tier. It runs on Cloudflare's free plan, and the MIT license lets you host your own copy.

Do friends need their own Netflix or Hulu account?

For the paid sites, yes: each person streams from their own account. YouTube and your own videos need none.

Why isn't Backrow in the Chrome Web Store?

Not yet. Loading it in Developer mode takes a minute and runs the same code you can read on GitHub.

Do I need a Backrow account?

No. An account only keeps your photo, name and color on every browser, encrypted with a key made from your password.

Does the extension run in Firefox or Safari?

The extension is Chromium-only for now. Friends can watch a video streamed from your computer in any modern browser.

Can I run my own Backrow server?

Yes. It runs on Cloudflare, and the README on GitHub has the self-host steps.

Where does my own video go?

Only to your friends' screens, over an encrypted connection. It's never uploaded or stored.

How close does Backrow keep the players?

Pauses and seeks reach everyone in well under a second. A small drift is closed by speed, not a jump.

Stream a video file from your computer

Nothing is uploaded. Your browser streams the file straight to each friend, encrypted end to end, and friends watch in any browser, phones included.

The invite link

Every invite link ends in a secret key, the part after the #. Browsers never send that part to any server, so Backrow's server only passes along scrambled data.

What the Backrow server can see

Encrypted end to end

  • Chat messages and reactions
  • Names, colors and the show or file
  • Play, pause and seek positions

What the server sees

  • A random party id
  • How many are connected
  • When messages are sent, and their size
